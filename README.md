# 三语背单词 · 四六级 / 雅思 / 日语 N1–N5

一个纯静态单文件背单词网页：收录英语（四六级、雅思）与日语 N1–N5 词汇，提供三语释义、艾宾浩斯每日复习、单词拼写测验与学习统计，手机、平板、电脑浏览器均可使用。

- 在线访问：https://sakuratearswind-ops.github.io/3-kinds-of-languages-vocab/
- 仓库地址：https://github.com/sakuratearswind-ops/3-kinds-of-languages-vocab

## 功能特性

- **今日复习**：按艾宾浩斯记忆曲线自动安排到期单词，六次复习间隔为 **1 / 2 / 4 / 7 / 15 / 30 天**；标记「已掌握」后不再排入复习队列。
- **学习新词**：按四六级、雅思、日语分类选词，翻卡查看释义后加入学习计划，次日进入第一次复习。
- **单词拼写**：可按词库筛选、选择 10 / 20 / 50 题或全部出题；日语单词**汉字与假名两种写法均判对**，支持首字母提示，结束后给出正确率与错题清单。
- **词库浏览**：全部分类筛选，支持单词、假名、罗马音、中文、英文、日语释义全文搜索；点击词条展开三语释义与发音。
- **学习统计**：学习中 / 已掌握数量、连续打卡天数、近 14 天学习热力图、各分类掌握进度。
- **三语释义与发音**：每条词条展示中文、English、日本語释义；英语 / 日语发音调用浏览器自带语音合成（SpeechSynthesis）。
- **进度本地保存**：学习记录与打卡进度保存在浏览器 localStorage；支持**导出 / 导入 JSON 进度文件**，在不同设备间迁移。

## 快速开始

### 在线使用

直接打开上方在线地址即可，无需安装任何软件。

### 本地运行

下载仓库中的 `index.html`，用任意现代浏览器（Edge、Chrome、Safari 等）双击打开即可，无需服务器、无需联网构建：

```text
index.html   # 唯一入口文件，样式与脚本全部内联
```

> 发音功能依赖浏览器语音合成；部分浏览器 / 系统需要联网或安装对应语言语音包。

## 使用说明

| 模块 | 操作 |
| --- | --- |
| 今日复习 | 每天打开页面即显示到期单词；点击卡片背面查看释义，再选择「认识 / 不认识」。 |
| 学习新词 | 选择词库分类，翻卡后点「加入学习计划」，或「跳过」。 |
| 单词拼写 | 选择题库与题量 → 开始答题 → 提交判分；可查看错题、再来一轮。 |
| 词库浏览 | 顶部筛选分类，搜索框输入关键词；点击词条展开详情与发音。 |
| 学习统计 | 查看掌握进度、连续打卡与近两周学习记录。 |
| 进度迁移 | 在旧设备点「导出进度」下载 JSON 文件，到新设备点「导入进度」选择该文件。 |
| 清空记录 | 在统计 / 设置区点「清空记录」，会删除本机全部学习进度，不可恢复。 |

## 词条数据结构

词库内联在 `index.html` 的 `WORD_BANK` 数组中，每条词条字段如下：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `id` | 词条唯一标识 | `cet01` / `rb1543` |
| `cat` | 分类：`cet` 四六级、`ielts` 雅思、`jp` 日语 | `jp` |
| `word` | 主词条（英文单词 / 日语汉字词） | `abandon` / `直面` |
| `ph` | 英语音标（日语词条留空） | `/əˈbændən/` |
| `kana` | 日语假名（英语词条留空） | `ちょくめん` |
| `romaji` | 罗马音（多数字条留空） | — |
| `zh` | 中文释义 | `面对，直面` |
| `en` | 英文释义 | `to face directly` |
| `jp` | 日语释义 | `直面する` |
| `lv` | 日语级别标签：`N1`–`N5`（英语词条无此字段） | `N1` |

## 技术实现

- **技术栈**：原生 HTML + CSS + JavaScript，无框架、无构建工具、无第三方依赖。
- **数据存储**：浏览器 localStorage，键名 `sanyu_vocab_progress_v1`（学习进度）、`sanyu_vocab_meta_v1`（打卡与统计）。
- **复习调度**：艾宾浩斯间隔 `[1, 2, 4, 7, 15, 30]` 天，按词条下次到期日期判断是否进入今日队列。
- **页面结构**：单页内 hash / 视图切换，包含今日复习、学习新词、拼写、词库浏览、统计五个视图。
- **部署**：GitHub Pages，从 `main` 分支根目录发布。

## 数据来源与说明

- 英语与日语词条分别来自配套词汇书籍的整理与 OCR 提取；**OCR 词条可能存在识别误差**，释义、读音请以原书为准。
- 受提取条件限制，部分词条的罗马音、英文释义或日语释义缺失，页面对应位置留空，未做编造补全。
- 本项目为个人学习工具，词库内容版权归原书作者 / 出版社所有，请勿用于商业用途。
